## Current builds

### Spotter *(private repository)*

A privacy-first, local document-intelligence workspace for macOS with a responsive browser experience and a Flutter mobile companion. Spotter supports document and receipt scanning, handwriting review, barcodes, trading cards, drawings, business cards, source-linked correction, and reviewed Word, PDF, text, and JSON exports. Recognition stays on the user's Mac through Apple Vision and optional local AI readers. Its current verified baseline includes hundreds of Python, JavaScript, and Flutter tests; physical-device qualification and release packaging remain in progress.

### [Gamer-Z-Paradise](https://www.gamer-z-paradise.com/)

A live gaming discovery, editorial, community, creator, and commerce platform built as a TypeScript monorepo with Next.js, React, Prisma, PostgreSQL, Playwright, accessibility automation, GitHub Actions, and Vercel. The product includes a public experience, authenticated staff CMS, governed publishing, moderated community features, commerce discovery, analytics, and an isolated marketplace sandbox.

### JARVIS *(private repository)*

A local-first realtime voice console and project operating system for Gamer-Z-Paradise. JARVIS combines a native Windows shell, OpenAI Realtime voice, a durable local project brain, visual creation workflows, permissioned Codex task preparation, evidence tracking, and explicit approval boundaries. The implementation spans JavaScript, C#, WebView2, SQLite, and a local-only service architecture.
